# Samurai Time ⏱️🗡️

Samurai Time é um jogo 2D de ação em salas desenvolvido para a GameName Jam.

## 🏯 Sobre o jogo

Você controla um jovem samurai preso em um templo amaldiçoado, agora tomado por espíritos inquietos.  
Ao encontrar uma katana misteriosa, ele adquire a habilidade de congelar o tempo ao desembainhar sua espada.

Seu objetivo é atravessar as salas do templo, derrotar os inimigos e encontrar uma saída.

## 🎮 Mecânicas

- Ataque básico com espada embainhada
- Time Stop (habilidade especial ao desembainhar)
- Sistema de salas conectadas por portas
- Dash (em desenvolvimento)
- Pulo duplo

## ⚔️ Inimigos

- Fantasmas com movimentação simples (patrulha linear)
- Mais variações planejadas

## 🚧 Estado do projeto

O jogo ainda está em desenvolvimento.

- Sistema de salas funcional
- Movimentação básica do jogador

## 🛠️ Tecnologias

- GameMaker Studio 2
- GML (GameMaker Language)

## 🎯 Objetivo da Game Jam

Desenvolver um jogo com foco em mecânica principal simples, porém interessante, explorando o uso estratégico do tempo no combate.

## 📌 Controles (exemplo)

- A / D → mover
- Espaço → pular
- Q → dash
- M1 → atacar
- U → ativar time stop
- R → Reiniciar Sala

*(os controles podem mudar)*
